## 角色屬性 {#attributes}

各项属性在原版里的实际作用（重制版的计算与原版相同）。属性都存成 16 位整数，最大 32767；表中的「上限」是超过后会被截掉、或再高也没有用的值。

| 属性 | 作用 | 上限 |
|---|---|---|
| 生命 | 降到 0 就倒下 | 9999。每场战斗开始时，参战角色的生命和生命上限超过 9999 的部分会被永久截掉 |
| 靈力 | 施放法术和部分招式时消耗 | 9999，同生命 |
| 體力 | 使用部分招式和饰品指令时消耗 | 9999，同生命 |
| 力量 | 战斗中的攻擊 = 力量 + 装备的攻击力（装备加的力量同时加到攻擊）。普通攻击的伤害 = 攻擊 + 随机 1～（等級 ÷ 3 + 3）− 敌人防禦，不超过敌人防禦时伤害为 1；攻擊提升状态加 200%，和招式同属性的五行攻擊提升再加 30%，攻擊下降按状态的回合数减少一定比例 | 攻擊按 16 位有符号数计算，超过 32767 时溢出，伤害反而只剩 1 |
| 耐力 | 战斗中的防禦 = 耐力 + 装备的防御力；防禦提升状态加 200%。只减少敌人普通攻击的伤害：伤害 = 敌人攻擊 + 随机 1～（敌人等級 ÷ 3 + 3）− 防禦；不超过防禦时只受 0～1 加随机 1～（敌人等級 ÷ 3 + 3）的伤害。法术伤害不看防禦 | 没有截断；高过敌人的攻擊后再高也没用 |
| 智慧 | 法术等按招式数值计算的伤害，额外加随机 1～（等級 + 智慧）÷（5～9）。用带异常状态的招式攻击敌人时，智慧每高出敌人的智慧 20 点，中异常的机率加一成 | 没有截断 |
| 敏捷 | 战斗中行动条每帧增加「敏捷 ÷ 4」（加速状态时敏捷先加 40，減速时减 30），满了就轮到行动。行动条的满值 = 100 ×（20 − 戰鬥速度），戰鬥速度在「環境設定」里设定，0～11 | 达到满值的 4 倍后一帧就满，再高也没用：戰鬥速度 11 时为 3600，0 时为 8000 |
| 閃躲 | 原版不显示在状态页（重制版显示在五行抗性右边）。敌人攻击时，我方连续 13 次没闪开之后，每次掷 0～9，小于閃躲值就闪开；连续 26 次没闪开时下一次必闪；有人刚闪开后的下一次一定不闪。隐身状态时九成闪开。我方四人共用这个连续次数 | 10，10 以上在可以掷时必闪。战斗中只取 0～255，超过 255 会绕回 |
| 異常 | 原版不显示在状态页（重制版显示在五行抗性右边）。敌人攻击时掷 0～9，大于異常值才可能中异常状态，所以越高越好：中招机率为（9 − 異常）成 | 9 以上不会中异常。变成负数时按很大的数比较，同样不会中 |
| 默契 | 没有作用：战斗和其他计算都不读取，只在升级时显示增加了多少 | — |
| 反應 | 没有作用，同默契 | — |
| 好感 | 原版不显示（重制版显示在反應下面）。小雪和玉儿入队时设为 100，之后剧情里先和谁说话、怎么选择时增减，其他角色的不变，影响结局，见攻略「結局與好感度」 | 存为 0～255 的一个字节，减到 0 以下会绕回 255 附近 |
| 五行抗性 | 状态页的 [金] [木] [水] [火] [土] 五个百分比。受到某个属性的攻击时，按五行生剋各取一项：一项按百分比减少伤害，一项按百分比增加伤害，一项不为 0 时把伤害变成按该百分比的回复。金：減 [火]、加 [木]、回復 [水]；木：減 [金]、加 [土]、回復 [火]；水：減 [土]、加 [火]、回復 [木]；火：減 [水]、加 [金]、回復 [土]；土：減 [木]、加 [水]、回復 [金] | 每项 −128～127 |
| 等級 | 普通攻击的随机加成是 1～（等級 ÷ 3 + 3），法术的随机加成也计入等級 | 战斗胜利升级只到 60 级 |

## 收化 {#absorb}

「煉妖」里的「收化」能否成功，看敌人等级减去出手角色等级的差。表中的「生命」是敌人当前的生命，「上限」是它的生命上限，除法取整数。

| 敌人比角色 | 生命够低时必成功 | 生命不够低时 |
|---|---|---|
| 高 12 级以上 | — | 必失败 |
| 高 7～11 级 | 生命 ≤ 上限 ÷ 4 | 必失败 |
| 高 1～6 级 | 生命 ≤ 上限 ÷ 3 | 掷骰：高 1 级 16%、2 级 11%、3 级 6%、4 级 1%、5～6 级 0% |
| 同级～低 4 级 | 生命 ≤ 上限 ÷ 3 | 掷骰：同级 21%，每低 1 级加 10%，低 4 级 61% |
| 低 5～9 级 | 生命 ≤ 上限 ÷ 3 | 掷骰 81% |
| 低 10 级以上 | 不看生命 | 必成功 |

例外：

- 头目（Boss）和不能收化的妖物，一律失败。
- 「人族」与「其他」类（神魔異事錄的分类）的敌人，按上表一律失败，只能靠「誘餌」。
- 「誘餌」先用掉一件诱饵：诱饵对应的类别和妖物相同时，不看生命和等级，只掷一次 0～9，小于诱饵的数值就成功；类别不同时按上表判定。
- 「收化」同一种妖物已经成功过 20 次以上：必成功。「誘餌」没有这一条。
- 失败时敌人可能因此暴怒。

调试模式下战斗中按 Ctrl+F2 切到「絕對靈契」，下一次「收化」或「誘餌」必成功，连头目也收得下（判定时只要「絕對靈契」开着就不看上面的条件）。它只管一次：这次收化结束（不论成功失败）或在选目标时取消，就自动变回「正常靈契」，没有提示；再收化前要再按一次。

## 絕技點數 {#specials}

每个角色另有一份「絕技點數」。点数达到最近学会的絕技所列的数值（见「絕技一覽」）后，在战斗胜利结算时学会下一个絕技。

### 加点

| 时机 | 点数 |
|---|---|
| 用「施放」为「絕技」的絕技命中敌人（见「絕技一覽」） | +2；打倒敌人再 +5 |
| 用「施放」为「法術」的絕技 | 每次 +2；打倒敌人不另加 |
| 战斗胜利 | 站着且由玩家操作的角色 +1；敌人有 3 只以上再 +1。用一招让敌人全体直接倒下而取胜的战斗不加 |
| 奇術、普通攻击、物品、饰品指令 | 不加 |

- 一场战斗里多次使用都会累加，每次命中都加，没有上限；点数在出手时就加上。
- 被自动操作、客串、灵兽与已倒下的角色，胜利时不加。
- 已学完全部絕技的角色不再加点。

### 学会

- 只在战斗胜利结算时判定：点数达到要求就学会下一个絕技，点数归零，超出的部分不保留。
- 每个角色一场战斗最多学会一个。逃跑的战斗不判定，已加的点数保留到下一场胜利。
- 使用絕技要怒氣滿。
