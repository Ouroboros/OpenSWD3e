OpenSWD3e軒轅劍參外傳 天之痕 · 重制执行程序

《軒轅劍參外傳 天之痕》的重制执行程序。它取代原版的 swd3e.exe，读取你已安装的原版游戏资料，在现在的 Windows 上直接运行。

剧情、战斗、数值与各种规则都和原版一样，连原版的小 BUG 也保留；会让游戏崩溃的问题则已修正。

本项目不含任何游戏资料，需要你已有原版游戏。

神魔異事錄：仿游戏图鉴的网页，列出全部怪物的数值、五行承受伤害、法术、可偷的物品、掉落物品、狂暴条件和说明，也收录了游戏图鉴里没有的剧情对手，可以搜索。

安装与运行

  1. 准备好原版游戏目录，例如 E:\Game\swd3e。
  2. 解压后得到 OpenSWD3e 文件夹，里面有 swd3er.exe、asset 文件夹和设置文件 swd3er.toml。可以整个放在任意位置，也可以把里面的东西放进游戏目录。
  3. 如果没有放进游戏目录，用记事本打开 swd3er.toml，在 [paths] 里写上游戏目录： 
    [paths]
data_dir = 'E:\Game\swd3e'
  4. 运行 swd3er.exe。

第一次启动时，原版保存在游戏目录 Env.dat 里的音量、按键等设定会自动导入一次。

设置

下面这些是重制版新增的设置。在标题画面的「環境設定」或游戏中按 Esc →「設定」里都能调整，改了立即生效并保存。画面相关的几项在「顯示設定」子页里。

设置默认作用
啟動畫面开关闭后启动时跳过启动画面，直接进入标题画面
平滑畫面开按显示器刷新率画出移动、淡入淡出等动态，高刷新率显示器更流畅；关闭后和原版一样每 35 毫秒画一次
垂直同步开等显示器刷新再显示，消除画面撕裂
幀率上限自動每秒最多画几帧；只在平滑畫面开启时有效
繪製倍率自動平滑畫面按几倍精度绘制，倍数越高移动越细，也越耗 CPU；只在平滑畫面开启时有效
地圖填滿开地图填满宽屏窗口，能看到更大范围；菜单、战斗等画面仍是 640×480

exe 旁边有两个设置文件：swd3er.toml 是你自己的设置，程序不会改动它；swd3er.default.toml 是游戏自动保存的设置。两个文件写了同一项时，以 swd3er.toml 为准。

隐藏功能

以下都是原版就有的功能。

随时可用的按键

按键作用
F8暂停／继续游戏
P截图（地图上或战斗中），存到游戏目录的 ScrnShot 文件夹
Esc（播放影片时）跳过影片

调试模式

在 swd3er.toml 的 [game] 里写上 debug = true，进入游戏后在地图上同时按住右 Ctrl、右 Shift、Home、End，即可打开下面这些按键。

按键作用
F12 或 Ctrl+S打开存档画面
Ctrl+L打开读档画面
Ctrl+F立即进入一场战斗（遇敌开启时）
Ctrl+F9快速跳过剧情文字（再按一次关闭）
Ctrl+F1／Ctrl+F2显示调试信息／地图格子
Ctrl+F3穿墙（再按一次关闭）
Ctrl+Tab 加小键盘 + -调整地图动画速度
F4打开秘技对话框
F6大部分物品各得 10 个
F7进入升天小游戏
Ctrl+Q结束游戏
