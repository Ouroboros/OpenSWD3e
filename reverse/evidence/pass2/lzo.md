# 第二遍：LZO1X 压缩与解压

## 0x0043DC40 LzoEncoder::Compress（14 位字典） — exact

汇编：长度 ≤ 13 → 尾部 = 长度；否则 0x0043DD30 得尾部与已写长度。尾部 > 0：输出仍为空且 ≤ 238 → 一字节 尾部+17；≤3 → 或入输出[−2]；≤18 → 尾部−3；否则 0 再接长长度（每个 0 记 255，末字节为余数）；复制尾部字面量。末尾 0x11 0 0，输出长度 = 写出字节数，返回 0。
对照：一致；输出缓冲越界见 deviations 59。调用方 0x00429BA0（地图缓存）。

## 0x0043DD30 LzoEncoder::CompressCore（14 位字典） — exact

汇编：ip 从输入+4 起，上限 = 末尾−13。哈希 = ((((b3<<6)^b2)<<5^b1)<<5^b0)×33 >>5 & 0x3FFF；主槽项 < 输入、距离 0 或 > 0xBFFF → 字面；距离 ≤ 0x800 或项[3] = ip[3] → 比较，否则次槽 (h&0x7FF)^0x201F 同样检查（远且第 4 字节不同 → 字面）；比较前三字节不同 → 字面。字面：最后查的槽 = ip，ip+1，未到上限继续。匹配：该槽 = ip；先输出 ip−ii 个字面（≤3 或入前两字节的操作码、≤18 一字节、否则 0+长长度）；逐字节比 3..8，9 字节全同则一直比到输入末尾。短匹配（3..8）：距离 ≤0x800 → M2 ((长−1)<<5)|((距−1)&7)<<2、(距−1)>>3；≤0x4000 → M3 (长−2)|0x20 + 距−1 两字节；更远 → M4 ((距−0x4000)>>11&8)|(长−2)|0x10 + 距−0x4000 两字节。长匹配：≤0x4000 时距−1，长 ≤33 → M3 (长−2)|0x20，否则 0x20 + 长长度(长−33)；更远时距−0x4000，长 ≤9 → M4 一字节，否则 M4 标记 + 长长度(长−9)；两字节 (距&63)<<2、距>>6。ii = ip，到上限即停。返回 末尾−ii。
对照：一致（长长度末字节以 u8(长)+零的个数写出，因末字节恒在 1..255 与原程序相减结果相同）；字典未初始化见 deviations 58（已用原版存档 8 个压缩块逐字节验证）。

## 0x0043E0A0 LzoEncoder::Compress（15 位字典） — exact

汇编：与 0x0043DC40 逐条相同，只调用 0x0043E190。对照：一致。调用方 0x0048AA80（名声存档，Fame::DictionaryBits = 15）。

## 0x0043E190 LzoEncoder::CompressCore（15 位字典） — exact

汇编：与 0x0043DD30 逐条相同，仅掩码 0x7FFF、次槽常量 0x401F。对照：一致（secondary = (1<<14)|0x1F）。

## 0x0043E500 LzoDecoder::Run — exact

汇编：首字节 > 0x11 → 复制 首字节−17 个字面，<4 时读指令直接进入匹配，否则进入字面后状态。指令 <16：字面串，0 时累加 255 并加 15 加下一非 0 字节，复制 长+3。字面串后指令 <16 → M1：距离 = 0x801 + (指令>>2) + (下字节<<2)，复制 3。匹配：≥0x40 M2 距离 = 1 + ((指令>>2)&7) + (下字节<<3)、长 = (指令>>5)+1；≥0x20 M3 长 = 指令&31（0 时扩展 +31）、距离 = 1 + (两字节>>2)、长+2；≥0x10 M4 远位 = (指令&8)<<11、长 = 指令&7（0 时扩展 +7）、远 += 两字节>>2，为 0 即结束，否则距离 = 远+0x4000、长+2；<0x10 M1 距离 = 1 + (指令>>2) + (下字节<<2)、长 2。匹配后尾随字面 = 输入[−2]&3，为 0 读新指令，否则复制后读指令进入匹配。结束：输出长度 = 写出字节数；输入正好用完 → 0，未用完 → −8，超出 → −4。
对照：一致（双字复制只在不重叠时使用，结果与逐字节复制相同）；不检查边界见 deviations 10。
