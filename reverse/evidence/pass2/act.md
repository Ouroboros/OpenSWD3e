## 0x004377B0 ActArchive::Get — exact

## 0x00437920 ActArchive::LoadDirect — exact

## 0x00437AA0 ActArchive::CacheLoad — exact

汇编：0x00436BD0 载入整条写 0x004F513C，为 0 → 0；链号 = 动作号&0xF，动作号为 0xFFFF 时取子号&0xF；该链计数 +1；新 0x18 字节节点（清零）：+4 动作号、+0x14 数据、+0xC 长度，插到链首；缓存字节 += 长度；0x00436B80(数据, 子号) 写 0x004F513C，返回其是否非 0。
对照：一致。

## 0x00437BB0 ActArchive::CacheFind — exact

汇编：0x004F513C 清 0；链号同上；从链首找 +4 = 动作号（不比子号）的第一个节点，找不到 → 0；不在链首时移到链首；0x00436B80(数据, 子号) 写 0x004F513C，返回 1。
对照：一致。

## 0x00437C50 ActArchive::CacheEvict — exact

汇编：在 16 条链中取计数最大者（无符号严格大于，相等取前者）；缓存字节 ≥ 上限时循环：走到链尾节点，缓存字节 −= 其长度，释放数据与节点，前一节点 next 清 0，计数 −1，为 0 时结束，否则字节仍 ≥ 上限继续。
对照：一致。源码对空链的跳过不可达：上限只由 Game 设为 0x80000（>0），触发淘汰时缓存字节 > 0，计数最大的链必有节点，且计数与节点数同步，计数归 0 即停。

## 0x00437D10 ActArchive::CacheClear — exact

汇编：对每条链先将链首清 0，再逐节点缓存字节 −= 长度、释放数据与节点、计数 −1。
对照：一致。

## 0x00436C80 ActArchive::Run — diff → exact

汇编：hold(+0x9C)=1 且帧(+0x4A)≠0 → 1；动作号为 0 → 1。方向(+0x34)、动作(+0x08)、动作号(+0x00)依次与上次值比较，不同时记下新值并内联同一段重置：+0x44/+0x46/+0x42、+0x24/+0x28/+0x10/+0x14/+0x2C/+0x30、+0x58/+0x5A/+0x7A/+0x7C、+0x92/+0x90/+0x91、+0x66/+0x68/+0x6A/+0x6C、+0x7E..+0x8A 七个灯值、+0x8C/+0x8E/+0x8F、+0x98/+0x9C/+0xA0 清零，旗标与 0x80000000（换方向）或 0x80000003 相与，0x004F5160=1。按 0x004F516C=1 取 0x004377B0，否则 0x00437920（子号 = 动作+方向），结果写 +0x54，为 0 → 0；0x004F5160=0。延时 +0x44≠0 → 减 1 返回 1。+0x50 清 0 后循环读字（位置先加 1）：'DE'：循环计数 +0x8C=0 时 hold=1 则位置退回，返回 1；否则按回合（+0x41）与 +0x8E/+0x8F 判断：等于起点 → 1；等于终点时非 0x4000 则计数减 1，低 15 位为 0 时计数清 0、位置留在其后，否则位置 0，返回 1；大于起点 → 1；否则清 +0x58/+0x5A 继续。'VO'：计数为 0 时 hold=1 位置退回否则位置 0，返回 1；否则同上（留位 0）。'2O'：计数为 0 时延时为 0 则 +0x98=1，位置退回，返回 1；否则同上（位置退回）。其余指令先设延时 = +0x46，速度 +0x48 为负时取其低 15 位，再按指令（ASCII 双字节）分派；YX、HW、GC、RC、BC 读第二个值不前移；CS 两字段同值，+0x94=1 或 0x004F5400=1 时旗标 |=0x80 并以 (x, y, (i16)值, (i16)值) 调 0x00423630，随后无条件写 0x004F5120、0x004F517C、0x004F517E；PL 在 +0x8D 的 0x80 未置时计数 = 第三值|0x8000（与 0xFFFF 比较后重写的为同值）；AP 回合 +1；未知指令只设延时。
对照：重置字段、旗标掩码、三种循环指令的各出口、每条指令的取值、前移与位宽均一致；越过条目末尾见 deviations 26。
差异：'CS' 调用的 0x00423630 即 Painter::SetZoom，源码中回调从未接上，战斗中（0x004F5400=1）执行 'CS' 的动作只置旗标 0x80（缩放绘制）而不设缩放，按此前残留的缩放参数绘制。数据扫描（tmp 中按指令长度逐字解析六个 .act）显示 all_char.act 有 27 处、all_magic.act 2 处、all_map1.act 1 处 'CS'，战斗单位脚本确实使用。
修正：Game 构造时接上回调，经 smooth::SetActZoom 在执行时设缩放：正在录制场景时录进当前场景（ScenePainter 构造时登记于 BattleServices::recording，析构时恢复），否则录进战斗帧场景，都没有时直接设画笔；Peek 不调用。名称按此改为缩放（zoomX/zoomY、FlagZoom、ZoomStart、zoomEnabled、lastZoom*，指令 Zoom）。复核：完整函数重新对照一致。
