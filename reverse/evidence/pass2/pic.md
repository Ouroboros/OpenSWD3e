# 第二遍：pic（RLE 编解码）

方法见 reverse/analysis/pass2-method.md：先只读 asm 推导，再对照 src/pic/rle.cpp。

## 0x00401000 RleCodec::Encode — 差异已修正，exact

汇编推导：
- 参数 (src, &size, width, height, format)；format==0x10 走 16 位，否则 8 位，表头写 magic（word 0x004EF584）、宽、高、format 低 16 位（16 位路径写 0x10）。
- 行数按无符号 `dec/jnz` 计数，高为 0 不进行；每行是 do-while：第一个像素无条件处理，之后 `x <= width` 无符号比较。
- 行标志：行首像素（8 位时零扩展）等于 16 位 fill（0x004EF588）或 skip（0x004EF530）时为 0，否则 0x8000。
- 分类：先比 fill，相等再比 skip，同时等于两者算 skip（0x8000）；只等于 fill 算 fill（0xC000，置 arg_4 低字节为 1，结尾 `or [buf+7],80h`）；其余为字面段。
- 字面段：首像素无条件写出、计数 1，`x+计数 <= width` 时继续读下一像素，遇 fill/skip 停；计数写为不带 kind 的 u16。
- 游程：`x+计数 <= width` 时比较 src[计数] 与游程色；16 位为 word 比较，8 位续扫为零扩展字节对 dword 0x004EEE90／0x004EEEC4 比较。两个 dword 只在 0x004275D3、0x004275E7 整 dword 写入 1、3，其余为 bss 的 0，与字节比较等价。
- 行头 = (行长+2) | 行标志，行长初值 2，字面 16 位 +2+2n、8 位 +2+n，游程 +2；行尾写 0；全部结束写 0，大小即实际字节数；临时块 6·w·h（8 位 3·w·h）复制到按实际大小的新块。

对照：
- 差异：源码字面段为 `for (; x+len <= width; )`，宽为 0 时写出 0 个像素、计数 0；汇编无条件写出首像素、计数 1。改为 do-while，首像素无条件写出。
- 宽、高按有符号 int；负值在原程序中读写越界，已并入 deviations.md 0x00401000 行。
- 其余分支、位宽、行标志（8 位与 16 位色比较）、fill 旗标、行长计算均一致。
- 调用方：battle_frame.cpp（640×480）、menu_ghost.cpp（kChartSide），宽不为 0。

## 0x004014B0 RleCodec::Decode — 差异已修正，exact

汇编推导：
- magic 零扩展 word 对 dword 比较，不等返回 0；宽、高、format&0x7FFF 先写出再检查 format，非 0x10／8 返回 0（4 个调用方都不读这三个输出）。
- 分配 w·h·2（8 位 w·h），32 位乘法；0x0043DA70 对有符号 ≤0 的大小返回 NULL，否则分配并清零（`rep stosd/stosb`）。
- 行头为 0 结束；每行码为 0 结束；kind 0 字面按计数复制（计数≥1）；0x8000 写 skip，0xC000 写 fill，计数 = 码&0x3FFF，16 位 `cmp cx,dx` 计数为 0 时回绕 65536 次；0x4000 不输出、不消费数据。返回分配块。

对照：
- 差异：源码按 size_t 分配，宽或高为 0 时返回空像素的成功结果；原程序得到 NULL（0x0048CA10 据此弹维护错误框）。改为按 32 位计算大小，有符号 ≤0 时返回失败；有段码时原程序写入 NULL，登记于 deviations.md 0x004014B0 行（越界、空指针）。
- 其余一致。

## 0x00401680 RleCodec::ConvertToDisplay — exact（删去死代码）

汇编推导：magic 不等返回 0；三个输出指针非空才写（宽、高、format&0x7FFF）；format≠0x10 返回 0；逐行逐码，kind 0 时调用 0x00427680(指针, 计数&0xFFFF) 原地转换并跳过像素；行旗标 arg_0 只写不读。返回 1。

对照：一致。源码为“计数 0 的字面码”保留的分支是死代码（kind 0 且计数 0 的码即 0，是行结束码），已删除并更正注释。

## 0x00401780 RleCodec::ConvertTo16 — exact

汇编推导：magic 不等返回；format≠8 时调用 0x00401680 并把宽、高写回图片 +0xC/+0xE；8 位：工作块 4·w·h，表头 format = (fmt&0x8010)|0x10；每行：行头槽、首码照抄、行长初值 4；字面按调色板（图片 +8，u16 表）取色后调 0x00427680 转换；之后每个码（含结束 0）照抄、行长 +2；行头写纯长度；结束时在下一行头槽写 0 并多计 2 字节；释放旧数据（不释放调色板），新块按计数复制，写回 +0 与 +0x10。

对照：一致。deviations.md 0x00401680 组行按汇编更正：删去不可能的“字面计数 0”；补登记 4·w·h 为 0 时工作块 NULL、调色板查表不限范围。

## 0x00401950 RleCodec::ConvertTileTo16 — exact

汇编推导：调色板 0x200 字节后为 8 位 RLE；magic、format=8 才转换；工作块 2·w·h+0x1000；首个行头槽在表头后，ebp 初值 10；每行同 0x00401780，调色板取自块首；行结束写行长并预留下一行头槽；结束写 0 并多计 2；大小截为 16 位后分配复制，释放旧块（含调色板），写回指针与大小。

对照：一致（字面计数 `cmp cx,ax` 比较整个码，kind 0 时与计数相同且≥1）。

## 0x00438560 PictureHitTest — exact

汇编：列 = x−原点x、行 = y−原点y；列 <0 → 0；只在行 <0 时检查列 ≥ 宽（+0xC）→ 0；行 ≥ 高（+0xE，有符号）→ 0；首字 ≠ 0xFFFF → 0。从 +8 起逐行跳过 (行首字>>1)&0x3FFF 个字直到行号相等（相等时再跳过行首字），高 ≤0 不循环，行为负时扫完全部行；该处字为 0 → 0；宽 ≤0 → 0。逐段：段字的 0xC0 高位任一置位即按 (段+0x4000)&0xFFFF 计长（0x80、0x40 两支不可达），列 ∈ [位置, 位置+长]（两端都含）→ 0，否则位置 += 长、前进 1 字；字面段列 ∈ [位置, 位置+长] → 1，否则位置 += 长、前进 长+1 字；位置 ≥ 宽 → 0。
对照：一致（(字&0x7FFF)/2 与 (字>>1)&0x3FFF 相同）；越过数据见 deviations 49。

## 0x00438A30 ShiftPicture — diff → exact

汇编：平移量 ≤0 → 返回；首字 ≠ 0xFFFF → 返回；首行字清 0x8000；该字 0x4000（test ah,0xC0 时 0x8000 已清）置位 → 返回；模式 >3 → 返回。行字数 = 宽+3。0（上）：保存前 平移量 行（新分配，不查结果），高−平移量 >0 时逐行前移，保存的行写到 (高−平移量) 行处（≤0 时写回开头）。1（下）：保存末 平移量 行，从末行到第 平移量 行逐行取前 平移量 行，保存的行写到开头。2（左）、3（右）：缓冲 = 宽×2 字节，每行像素（跳过 2 个行首字）复制到缓冲，左移时前 平移量 个像素写到行尾、其余写到行首，右移时末 平移量 个像素写到行首、其余接在其后。最后释放缓冲。
对照：各模式的复制源、目标、长度与顺序一致；平移量等于高时写回原处也一致。
差异：源码在数据短于按宽高计算的行（含不足一个行首字）时直接返回，deviations 50 只登记了平移量越界。修正：扩充 deviations 50，源码不改。复核：完整函数重新对照一致。
