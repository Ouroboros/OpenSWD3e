# 第二遍：投影器（Projector）

## 0x00438700 Projector::Projector — exact

汇编：+0xB40、+0xB44 清 0；0x004388E0(0x500, 0x300)、0x00438950(640, 480)、0x00438DA0(0, 0, 640, 480)。角度 0..89：dirX = −1000，dirY = ftol(fptan(角 × 0x004AA688) × 0x004AA684)；91..179：dirX = 1000，dirY[91+k] = dirY[88−k]；180..269：dirX = 1000，dirY = −dirY[角−180]；271..359：dirX = −1000，dirY[271+k] = −dirY[88−k]；再置 dirY[180]=0、dirX[90]=0、dirX[270]=0、dirX[180]=100000、dirY[90]=−100000、dirY[270]=100000（下标由 +0x5A0、+0x700、+0x70C、+0x9DC 等偏移推得）。
对照：一致；0x004AA684 = −1000.0f（字节 00 00 7A C4），0x004AA688 = 0.017444444444444446（double 字节核对相等）。

## 0x00438830 Projector::Release — exact

## 0x00438880 Projector::Init — exact

对照：一致。

## 0x004388E0 Projector::SetBufferRows — exact

汇编：释放旧表；按 行数×4 分配，失败 → 返回 0（宽高不更新）；+0xB48 = 宽、+0xB4C = 行数；表[i] = i×宽；返回行数（≤0 时 0）。
对照：一致；行数 ≤0 时原程序分配失败不更新宽高，源码仍更新：不可达，调用方只传 0x300 与 0x00438880 的后备缓冲高度。

## 0x00438DA0 Projector::SetClip — exact

汇编：x<0 → 宽 += x、x=0；y<0 → 高 += y、y=0；x+宽 ≥ 屏宽 +0xB50 → x = 屏宽−宽；y+高 ≥ 屏高 +0xB54 → y = 屏高−高；+0xB5C = y、+0xB58 = x、+0xB60 = x+宽、+0xB64 = y+高，返回 y+高。
对照：一致。

## 0x00438E10 LineStep — exact

汇编：dx = 终x−起x、dy = 终y−起y，负时取反并记步向 −1；dx=0 → y += 步y；dy=0 → x += 步x；dx<dy → +0x18 += dx，> dy>>1（算术）时 −= dy、x += 步x，再 y += 步y；dx=dy → 两轴各走一步；dx>dy → +0x1C += dy，> dx>>1 时 −= dx、y += 步y，再 x += 步x；返回 x=终x 且 y=终y。
对照：一致。

## 0x00438EE0 Projector::Step — exact

汇编：dx = dirX[角]、dy = dirY[角]，负时取反记步向；dx=0 → y(+0x10) += 步y；dy=0 → x(+0xC) += 步x；相等 → 两轴各一步；dx<dy → +0x14 += dx，> dy>>1 时 −= dy、x += 步x，再 y += 步y；dx>dy → +0x18 += dy，> dx>>1 时 −= dx、y += 步y，再 x += 步x。
对照：一致（分支顺序不同但互斥条件相同）。

## 0x00438FA0 Projector::DrawScaled — exact

汇编：参数块 +0x2C/+0x30/+0x34 写三色调 0x004ED9A4/0x004EC180/0x004EC178；末行 = 像素 +(高−1)×宽；列数 = (宽<<10)/x 倍数、行数 = (高<<10)/y 倍数（有符号）；走子 A 角度 = +0x38、位置 = (+0x10, +0x14)，走子 B 角度 = (角+90)%360；行数 ≤0 不画。每行：0x00438EE0(A)，B 位置取 A、误差清 0；列从 +0x10 起，每列 0x00438EE0(B)（位置不用）；屏幕 x∈[0, +0xB50)、y∈[0, +0xB54) 时取像素：旗标 +0x28 bit0 置位取 末行+宽−列−行偏移，否则 末行+列−行偏移；等于 fill 或 skip 跳过；旗标 &0x16 时 0x004211A0(源, 屏幕[行表[y]+x], 1)，否则直接写；列累加 x 倍数取 >>10。行末行累加 y 倍数，行偏移 = (累加>>10)×宽；屏幕 y 从 +0x14+行数 逐行减 1。
对照：一致；镜像底行多读一个像素见 deviations 48。

## 0x00439250 Projector::DrawExplosion — diff → exact

汇编：+0x38=0 时 srand(time(0))，三色调取 +0x2C/+0x30/+0x34，像素数 +0x3C = 高×宽，+0x40=0、+0x38=1、+0x48 = 非 fill/skip 像素数，+0x44 = +0x48/20，+0x4C = 像素数/+0x24（有符号）。+0x24>0 且 +0x40 < +0x48/+0x26 → 0x00439890(块, 像素数/+0x24)。+0x40 ≤0 且 +0x24=0 → 返回 1。+0x24 ≥1 时画本体前 高−1 行：镜像（+0x28 bit0）时列 c 按 x+宽−c 裁剪、取行内第 宽−c 个像素、画在 x+c；否则按 x+c 裁剪、顺序取像素、画在 x+c；跳过 fill/skip，+0x28&0x16 时 0x004211A0 混色。粒子链 +0x50 逐个：+0x40 ≤ +0x44 时速度 +8 = rand()%(+0x22)+(+0x22)；走 速度 次 0x00438E10；寿命 +0xC −= 速度；寿命 ≤0 或位置落入目标矩形（+0x10..+0x10+0x14、+0x18..+0x18+0x1C）即移除，否则画 2×2 块：上一对在 x+1∈[0,宽)、y∈[0,高) 时画，混色时右上像素混色后再原样写入（为 fill 也写），下一对在 x+1、y+1 都在范围时画（跳过 fill）。移除：唯一节点 → 链首、空闲、+0x40 清 0，释放，返回 0；首节点 → 后继成链首；末节点 → 前一个成为空闲 +0x54；中间 → 前后相连；释放后 +0x40、+0x48 各减 1。返回 0。
对照：状态推进（smooth::ExplosionFrame::Advance）与绘制（Draw）一致，分支、顺序、随机数消费、移除规则相同。
差异：镜像本体按 x+宽−列 裁剪却画在 x+列，靠近顶行或末行时写到画面缓冲之前或之后；粒子在 x=−1、顶行时左像素下标为 −1。源码同样越界写且未登记。修正：Draw 中画面缓冲（屏宽×屏高）之外的像素不写，其余（含回绕到相邻行）照原样；登记 deviations（0x00439250 越界）。复核：完整函数重新对照一致。

## 0x00439890 Projector::ParticlePut — diff → exact

汇编：0x00509E7C=0 时取 +0x4C。链首 +0x50 为空时新分配 0x38 字节节点（失败弹框）、清零作链首，否则取空闲 +0x54。起点暂存 = (count, 未初始化)。尝试 count 次：旗标 0x40 → 下标 = (rand()×(rand()%28)) % 0x00509E7C；0x80 → % (+0x3C / +0x24)；否则 % +0x3C（rand 先取 %28 的那次）。像素为 fill/skip 跳过；+0x40 加 1；镜像时起点 x = 宽 − 下标%宽 + x，否则（非仅 0x80）= 下标%宽 + x；二者时起点 y = 下标/宽 + y（无符号），并写入走子起点与当前位置；仅 0x80 时节点位置不写、距离沿用上一粒子的起点。目标 x = rand()%+0x14 + +0x10，y = rand()%+0x1C + +0x18；距离² 32 位回绕，为 0 取 1；寿命 = rand() % ftol(sqrt(距离²，按无符号)) + +0x20（无符号除法）；速度 = rand()%+0x22 + 1；取 2×2 块（下标、+1、+宽、+宽+1）后置 fill；新分配空节点接在其后（失败弹框返回），前驱指向本节点，空闲 +0x54 = 新节点的 next（即空），下一次尝试用新节点。结束：+0x24 减 1，0x00509E7C += +0x4C，+0x24 为 0 时 0x00509E7C 清 0；返回 count。
对照：随机数次序、取点、起点、目标、寿命、速度、清块与收尾一致；越界、空闲指针为空或已释放、分配失败见 deviations 47，首个粒子起点 y 见 313。
差异：每放一个粒子后源码把空闲指针设为新空节点，原程序为空（直到本帧移除末尾空节点时改为前一个粒子）。现有调用顺序下下次放置前总会先移除该空节点，结果相同，但状态不同。修正：放置后空闲指针置空（end）。复核：完整函数重新对照一致，DrawExplosion 的移除规则随之不变。
