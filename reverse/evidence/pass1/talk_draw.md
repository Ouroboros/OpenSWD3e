# 第一遍：对话窗口绘制

## 0x00433C10 Talk::Draw — exact（实现在 smooth::TalkFrame::DrawAdvance／DrawWindowAdvance，绘制经 smooth 层的 Scene 延后执行）

- 入口：窗口链 0x004C66F8 为空时返回。建 40×单元 宽、11×单元 高的离屏面（0x0043C620）并清空，大字体目标设为同尺寸，锁定取像素后解锁，记下 advance（0x004C30D0）。
- 每个窗口：颜色 +0x2C、阴影 +0x2E、样式 +0x34 低字节、x 起 1、列 0、行 0、首行 0、选项号 −1、opening = 1。
  - Fade（0x40）：opening = 0；未 Typed 时 openStep+1（上限 4）、alpha = openStep×4；Typed 时 counter < 8 则 alpha = counter×2；alpha &= 0xF；框 = (x, y, x+宽+2×单元, 高+y)。
  - 否则 openStep+1 到 4 时 opening = 0，三种起点：FixedPlace（0x800）x0 = fromX + step×((x−fromX)/4)，y 偏移 = step×((y−fromY)/4)；有说话者时以角色坐标为起点并换算镜头左上（step×(镜头+x−角色x)/4 − 镜头，有符号截断）；无说话者（0xFFFD）同样以 fromX/fromY 换算。上 = y0+偏移−4，右 = x0 + step×((宽+2×单元)/4)，下 = step×(高>>2) + 上 + 8。
  - Overlay（0x80）：opening = 0，框 = (x, y, 宽+2×单元+x, 高+y)，edge = x；否则 DrawWindowFrame（0x00433720，帧取 frameAct +0x4A，边宽 0x10），edge = 左。裁剪 (edge, 上, 右+edge, 下+上)（原样保留这一组合）。
- 每帧：delay−1，advance 取回；全部跳过（0x004E6CFC）时 delay 0x8FFF、advance 1、空格计数 1；Enter 计数为 1 时空格计数 1；Skippable 且空格为 1 时第一次置 0x80000000、第二次置 0x40000000；Skipping 时 speed 0xFFFF，首次再设 delay 0xFFFF 与 0x20000000。
- PageFull|Typed 时：NoAdvance 且不全跳过 advance = 0；Typed：advance 原值非 0 置 Read，advance 非 0 置 0x200，空格不为 1 时清 advance 与 0x200，超时（(0x004C4654−shownAt)/100 > timeout 且 Timed）置 0x200 并 advance = 1；未 Typed：同样的 0x200 处理，advance 非 0 时置 Skipping，timeout 为 0xFFFF 时 NoAdvance 则 advance 取回，否则超时清 shownAt 后置 0x200、advance = 1；Fade：advance = 0，timeout 为 0xFFFF 时经过 < 0x10018 则 counter = 0x10，否则超过 timeout 时 counter−1（负数归 0），为 0 时置 0x200、advance = 1。都不是时 counter = 0x24，Skippable 则 advance = 0，否则 advance 非 0 置 Skipping。Choices（0x2000）：counter = 0x20，没有点击区（0x004E4DCC）时 counter = 1、advance = 1、置 0x200。
- 打字循环（opening 时不进入）：全部跳过时 advance = 1、本字标记清零。advance 非 0：非 Skippable 时 delay 0x8FFF；没有点击区时 PageFull 且 advance ≠ 2 翻页（page = typed，typed 处字节非负且不是 '%' 时 +1，去 0x4000/0x200/0x100，颜色、阴影、样式取页存值），否则 0x200 时关闭：非 FixedPlace 时说话者旗标 0x800 则跑动作（"Act Err(DlgMessage:Fr)"）、无说话者时领队 +0x26 清零，Blocking（0x10）时 0x004E6CDC = 0xC、玩家锁定计数减 1（不低于 0，保留 0x8000）；page 清除、空格两计数清零。
- delay ≥ 0 时到达 typed 即画出本段结束；delay < 0 时越过 typed 且本帧打过字则 delay = speed、typed = 当前、画出结束。"%Q"：画出，未 Typed 时记 shownAt、Fade 时 counter = 0x10，置 Typed，有点击区时 0x004E4DC8 |= 0x1000。(x+列)×单元 > 宽（有符号）或 "%N"：画出，(行+1)×2×单元 ≥ 高时置 PageFull、点击区旗标、"%N" 时 typed 越过它、记 shownAt、全部跳过或 Instant 时 typed = 当前、存页；否则换行（"%N" 时越过，首行偏移记第一次的 consumed）。
- 指令："%L" 到达 typed 时画出、page += 首行偏移、typed += 2 结束，否则越过；"%P" 画出、点击区旗标、typed 越过、shownAt、跳过时 typed = 当前、存页、置 PageFull 结束；"%S" 数字 speed = (数字 + 0x004C3654)×2（u8 数字），Skipping 时 0；"%C"／"D%"／"%G" 越过 3 字节、画出、x = x+列、列 0，分别设颜色与阴影／阴影／样式（0→4，1→0x10，其余照数字）；"%K" speed、delay 清零并置 Skipping；"%A" 读到 '.' 的数字（consumed 不计 "%A" 两字节，原有 BUG），ParseNumber，"%A" 时 PlaySound(0xC0, 音量 0x004C4F0C)，改为 "%a"；"%B" 置 Choices、选项号+1、画出、读到 '.' 的标签，选中（0x004E6CC0）时以 0x004AF728 颜色、样式 0x84 画并调用 0x0040E1C0 标记，否则普通画，背景 0xFFFE，x = x+列+长度；"%B" 时加 0x14 字节点击区（1，左 = 窗口x + (x−长度)×单元，上 = 窗口y + 2×行×单元，右 = 左+长度×单元，下 = 上+2×单元）到链尾，改为 "%b"；其余复制一字节、本帧打过字，负字节再复制一字节。
- 窗口收尾：opening 以外 edge = 左；0x004ED9BC = 像素，首像素 0xFFFF 改 0xFFFE，0x004E6D58 = alpha，DrawPicture(x, y, 40×单元, 11×单元, alpha ? 0x14 : 4)，清面。PageFull|Typed 且（ShowMark 未 Read 或非 NoAdvance）时画页标：Typed 用结束动作（0x004E54A8，图 0x004E54F2/F4）、否则下页动作（0x004E6C18），位置 右−动作x−4、下−动作y−8，模式 0。非 opening、有名牌且 page 未关时：15 行 0x004187A0（0x1C + 8×长度 像素，按对计）调暗 (edge+16, 上+行−16)，名牌框（nameAct +0x4A，左 edge+6、上 上−0x1B、右 长度+edge+8×长度+0x10、下 上−8，alpha，边宽 4），中字体阴影 0x004AF770、颜色 0x004AF730 样式 4 画在 (edge+0xC, 上−0x1A)，阴影清零。
- 全部窗口后：释放离屏面，裁剪 (0,0,0x27F,0x1DF)，advance = 0；page 已关的窗口摘链，说话者 +0x26 清零后释放。跑结束动作与下页动作，失败时都以结束按钮角色 0x004E5468 的 id/act/action/direction 报（"Act Err(DlgMessage:EndBtn)"、"…:NextPage"）。大字体目标恢复为 0x004B1E90/0x004B1E94（BackSize）。
- 常量与颜色表下标核对：TextColors primary 0x004AF720（[2] = 0x004AF728、[4] = 0x004AF730），secondary 0x004AF760（[4] = 0x004AF770）；TalkWindow 布局与旗标值见 src/game/scene.h。只改两处注释（0x004187A0、0x00435022..0x00435040）。
