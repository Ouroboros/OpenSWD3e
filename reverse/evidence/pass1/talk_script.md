# 第一遍汇编验证：talk_script（对话窗）

## 0x0040B370 Talk::SetupDialog — exact（修正后）

- 参数：窗口、记录、名牌文字、选项（低 15 位版式，0x8000 用偏移，0x10000 单行，0x20000 记入对话记录，0x40000 横向居中）、偏移 x/y。
- hasOrigin = fromX|fromY 非 0；fixed = 旗标 0x800。文本起点：版式 0 记录+4、1 记录+0xC、2 记录+8；单行且 fixed 时记录+4。（版式 ≥3 时原程序以窗口自身为起点并在量完后继续找下一个 %Q；调用者只传 0～2，见 deviations.md。）
- 逐字节找字 0x5125（"%Q"），分配 0x200 字节清零缓冲（+0x38/+0x3C/+0x40），复制到 %Q 为止（含），ExpandText 返回行数<<16|字数。选项 0x20000：在对话记录链表尾加节点，文字按 长度+8 复制。
- 尺寸：单行 宽=字数×单位、高=2×单位；版式 1 记录[4]、[5]×单位；版式 2 记录[2]、[3]×单位；版式 0 按行数 ≤3 → 16×6，=4 → 18×8，>4 → 20×10 单位。
- 说话者：记录[0] 非 0xFFFD 且非 fixed 时查角色，失败报 "設定對話窗(SetupDialog)"/"無效的角色號碼 或不在地圖上GUID(%d)"（0x004B0DA4/0x004B0DBC），释放文字缓冲、窗口 0x4C 字节清零，返回 0（实现以 page=Closed 表示文字指针为空）。
- 框动作：四个对话框动作（0x004E6880 起每个 0xA4）中找 id==记录[1]，找不到报 "SetupDialog"/"設定錯誤的對話框(act:%d)"（0x004B0D88）并用第 0 个；运行动作失败报 "Act Err(Dialog:Frame)"，格式 0x004B0D58，参数 act.id、动作、方向。有名牌时用对应名牌动作（0x004C27B8 起），名牌文字复制进 0x20 字节缓冲，运行失败报 "Act Err(Dialog:Caption)"（同样三项）。
- role=说话者（找不到或未查为 0xFFFD）、openStep=0、+0x26=0、delay=0、速度=文字速度×2、颜色与阴影 4、样式 4、next=0。旗标 0x80（叠加）：颜色阴影 5，有说话者时 lift = ShiftY[朝向] ≤ 0 ? 0x20 : −0x30。role==0 时角色 0 置于相机左上 +(0x40, 0x10)。
- 位置取记录[2]、[3]；0x40000 时 x 减半宽。单行且 fixed：x=偏移y−高−0x10（不足 0x10 取 0x10），y 不足 0x10 取 0x10，x+宽 <0x260 时 x=0x260−宽，y+高 <0x1D0 时 y=0x1D0−高（远边判断方向相反，原有 BUG 保留），返回 1。版式非 0、2 时返回 1。
- 无起点：role==0xFFFD 时 from=领队坐标，窗口中心对准它；role 非 0 时窗口中心对准角色（16 位截断）。
- 偏移：fixed 或无说话者加 ShiftX[1]、ShiftY[1]（0、−0x68，实现直接写 −0x68）；否则 0x8000 加偏移，不然加 ShiftX/ShiftY[朝向]（ShiftY 再加 lift）。表 0x004AA4C4/0x004AA4E4（tests/talk_test.cpp 比对 exe）。
- 夹取：x 负或 <0x1E → 0x1E；x+宽 ≥0x240 → 0x240−宽；y 负或 <0x28 → 0x28；y+高 ≥0x1C8 → 0x1C8−高。非 0x8000、非叠加、有说话者，且说话者屏幕坐标落在 (x−0x10, x+宽+0x30)×(y−0x10, y+高+0x40) 内（无符号）时再按朝向挪一次，夹取下限改为 0x18、0x20。返回 1。
- 差异（已修正）：两种动作失败的错误框原程序传 id、动作、方向三项，实现只传 id 其余为 0（并在 deviations.md 记为“取栈残值”，与汇编不符）；已改为三项并删除该条。
- 宽地图下屏幕坐标换算用 ScreenLeft/ScreenTop（增强，deviations.md 第 92 行已补列 0x0040B370）。

## 0x0040BB90 Talk::ExpandText — exact（修正后）

- 0xA8 字节对象记录缓冲清零；已用量 consumed=0；从头逐处理，直到字 "%Q" 或字节 0：
  - "%T"：consumed+=2；"%T" 后到 '.' 前的字符复制进全局缓冲（不限长度），consumed+=1（"%T" 与点共 3）；长度 ≥7（即 5 位以上）时补 '.' 报 "物品名稱代換"/"!! 警告 !!\n號碼字串太長\n%s"（0x004B0E04/0x004B0E14），仍继续；ParseNumber 失败：补 '.' 报 "錯誤的號碼字串\n%s"（0x004B0DF0），位置 +4、consumed 再 +1；LoadObject 失败：报 "找不到物品 %d"（0x004B0DE0），位置 +4、consumed 再 +1；成功：以 "%T号码." 为模式、物品名为替换，ReplacePrefix(上限 0x1FE−consumed)，位置与 consumed 各加名字长度。
  - 否则依次试三名角色（名字标记 0x004E4AF8、名字 0x004E4C30，每人 0x20 字节，姓 +0、名 +6、号 +0xC）的替换（上限为进入时的 0x1FE−consumed），成功时位置与 consumed 加名字长度，否则各加 1。
- 测量：字数 0、列 0、行 1；首字为 "%Q" 时返回 1<<16。%N、%L、%K、%P 跳 2 并换行；%S、%C、%D 跳 3；%B、%A 跳 2；其余字节计 1 字，列超过 20 时换行。遇字节 0 或 "%Q" 结束，返回 行<<16 | 字数。
- 差异（已修正）：成功替换 "%T" 时原程序的 consumed 先加了 3（0x0040BBF8、0x0040BC14），实现只加名字长度，后续替换的上限比原程序大 3；已改为先加 3、失败再加 1。

## 0x0040BEA0 Talk::ReplacePrefix — exact

- 模式为空返回 0；逐字节比较到模式结尾，不同返回 0；替换长度 n：把 at+模式长 起的 (上限−n) 字节移到 at+n（MSVC 静态库 memcpy，允许重叠），再写入替换文字，返回 1。上限−n 不为正时实现不移动（原程序以负数为长度复制越界），见 deviations.md。

## 0x0040BF20 Talk::AppendWindow — exact

- 从对话窗表头（0x004C66B0 哨兵，+0x48 为 next）走到尾，挂上新窗口并清其 next。

## 0x00433140 Talk::SeekScript — exact

- 角色 +0x14 = 偏移、+0x20 = 0，Seek(偏移 + 0x200)，读 0x8000 字节到剧本缓冲（0x004D1DA8 指向），返回 1。databases.h 的 script 成员注释改为 0x004D1DA8。

## 0x00433190 Talk::OpenScript — exact

- 关闭 0x004C2FA0，"%sTalk%d.dat"（安装目录，序号/2000+1）只读打开；失败时 “劇情資料(1)無法讀取/%s”（0x004B2D94）复制到 0x004C4658，第 9 字节改为 序号/2000+'1'，以 “檔案開啟”（0x004B2D88）报（%s 无参数，偏差已登记），发 WM_DESTROY（Game::Destroy），返回 0。
- 成功：Seek(序号%2000×4 + 0x200) 读偏移，写 +0x14、+0x20 = 0，Seek(偏移 + 0x200) 读 0x8000 字节，返回 1。

## 0x00433440 Talk::CommandsRole — exact

- 指令字为 0xA、0xB、0x2D 时 FindRoleOrPlayer(第二字) 找到且槽号等于参数返回 1，否则 0。

## 0x00433590 Talk::RoleVariable、0x00433620 Talk::FindRoleRecord — exact

- FindRoleRecord：从 0x004C65F0 起每 0x18 字节，首 dword 为 −1 结束返回 0；+2 字等于 id 时返回该记录。
- RoleVariable：无记录返回 0；记录 +0x16 字：模式 1 读（变量 1 低字节、2 高字节，零扩展）；模式 2 写（只换对应字节）；其余不动；返回 id。数据截断时的处理是重建的边界保护。
