# 第一遍：地图上的指针（0x0042B4C0）

## 0x0042B4C0 Talk::HandlePointer — exact（空指针、越界已登记；镜头取 ScreenLeft/Top 属宽地图增强）

- 领队 id 0x004D0AC4 为 0xFFFF 且控制角色动作为 0 或 0x34 时，从角色 1 起找：可见（0x8000）、非 Untalkable（4）、事件字 +0x1E 非 0、对话状态 +0x26 为 0，图（FindPicture(+0x8A, +0x8C)）存在且指针严格落在 (x − 动作x − 镜头左, y − 动作y − 镜头上) 起的宽高内（有符号比较）。找到且无旗标 0x20 时指针 9，旗标 0x40 时指针 0xA 并禁止区域。
- 游戏旗标 9 为 0、点击区域数 0x004E4DCC 非 0、控制角色站立（0/0x34）：0x0040DED0 找指针下的区域，指针 0xD；有区域时选择 0x004E6CC0 = 序号，左键按下且持续 1 帧时释放点击区域、清左键、调试输出 "\nButton[%d]Pressed"；返回。
- 找到的角色不是 −1、roleCount、控制角色，领队空、该角色对话状态 0、左键按下且持续 1 帧：方向 = DirectionToPlayer(角色 x + 宽×8, y + 高×8)；角色旗标 0x800 时存动作与方向、动作 0、延迟 0、方向 = 该方向，跑动作失败报 "Act Err(Talk:RoleTurn)"；控制角色动作 0、方向 = (d&~1)+((d−1)&1)、延迟 0，失败报 "Act Err(Talk:MRoleTFace)"；领队复制该角色的事件偏移/游标/事件/id/旗标/x/y；清左键；调试输出 "\nRoleEvent.GUID[%d].Talk[%d].Ridx[%d].RArgu[%x]"（FindRole 只取一个参数）。
- 否则：领队空、允许区域、站立时，取指针格（(指针+镜头)>>4，无符号）的区块低字节为区域号，FindRegion 后以旗标 &0xFFFF 查游戏旗标；真则指针 0xB，左键按下持续 1 帧时领队事件偏移/游标/旗标 0、事件 = 区域事件 &0x7FFF、x/y = 指针 &~0xF + 镜头、id 0xFFFD，控制角色存方向与动作后转向（同上公式）、动作 0、延迟 0，失败报 "Act Err(Talk:MouseActiveStory)"，玩家锁定 0x004C2FF8 = 0x8000，调试输出 "\nMapEvent.Talk[%d]"。
- 其余：AngleBetween(指针, 控制角色中心 − 镜头) 得距离，AngleToDirection 得方向；指针为 0xD 时改为该方向；控制角色在格点、未锁定、右键按下计数低 4 位非 0、距离 ≥ 16 时，方向 {0,4,7}/{1,5,6}/{2,4,6}/{3,5,7} 分别把右键计数写入上/下/左/右键（0x004D1678/0x004D1698/0x004D1668/0x004D1688，按键表 0x004D1638 起每项 16 字节）；有对话窗（0x004C66F8）且空格计数为 0 时空格 = 左键整项。
- 实现同此（常量逐一核对）。新增偏差行：区域号查不到时原程序读空指针 +0xC；格子越出区块表时读表外。
