# 第一遍：剧情指令解释器 Talk::RunEvent（0x0042BAF0）

逐命令对照，入口按跳转表 0x004321AC（命令 1..0x6C）、0x0043235C（0x6E..0xD6）与 0x0042F448 起的 0x400/0x401/0x402/0x3FFF 分支取得。全部命令核完后整体登记。

## 入口与循环

- 领队 id 为 0xFFFF 返回；事件偏移为 0 时：控制角色不在格点返回；id 非 0xFFFD 时 FindRoleOrPlayer 后该角色旗标 |= 0x80000；Talk<event/2000+1>.dat 打开失败报“SWD3-Talk”/“找不到 Talk%d”并 WM_DESTROY；偏移取 +0x200+4×(event%2000)，游标 0，剧本缓冲 0x8000 字节先填 0x0C 再读入，玩家锁定 |= 0x8000，跑控制角色动作（失败报 "Act Err(Talk:LoadTalk)"）。swd3e 没有 AIL_serve：实现里从正传带来的 9 处 AudioDevice::Serve 调用与该函数已删除（0x0049CE40 实为 AIL_shutdown 的导入转跳，归 AudioSystem::Shutdown）。
- 循环（0x0042BD21）：命令 = 字 &0x3FFF，写 0x004F4840（全库无读取）后分派；每条命令后（0x0042F77D）lastCommand 0x004F47E0 = 命令号（var_40，两处命令把它改作 0xFFFF，见各命令），系统旗标 4 置位或“继续”与 0x400 连续模式都为 0 时返回。实现原先缺 QuitRequested 检查且只在 `stopped` 为假时写 lastCommand：已改为与汇编相同；`stopped` 只服务于已移除的光盘检查出口 0x00432172，删除。

## 命令

- 1..6、0x59、0x5A 对话：说话者（0xFFF0 为事件角色）找到后写回操作数；窗口 0x4C 字节；无说话者时（事件角色非 0xFFFD 先写调试串 0x004B2BF8）取事件角色位置；0x004B2338 非 0x8000 时位置 = 镜头 + 它；版式 3..6 为 1、0x59/0x5A 为 2；5/6 旗标 0x40；0x004B233C 各位清零时依次加旗标 0x20、（0x004F4844==1 时超时 0x004B2340 与旗标 8）、0x400、0x80、2，版式加 0x8000、0x10000、0x20000，0x004F4848==1 加 0x40000；SetupDialog(名牌 0x004F43E0, 偏移 0x004F4838/0x004F483C)；说话者对话状态 2，奇数命令加旗标 0x10、状态 1、玩家锁定加 1；挂窗；按字节找 "%Q"（0x5125），游标到其后；各设置复位。Talk 成员注释的 swd32 地址已换成以上 swd3e 地址。
- 7/9：0x004B233C &= 0x7FFFFFFF / 0xBFFFFFFF；8：0x004F4844=1、超时=操作数。均前进并继续。
- 0xA/0xB：找到角色时设动作（延迟 0）或方向（延迟 0，之后旗标 |= 0x1000），CommandsRole(下一条, 角色) 为假才跑动作，失败报 "Act Err(Talk:ChangQQ)"/"(Talk:ChangDir)"；找不到时 UpdateRoleRecord(id, …, 0x1000, …, 0x8080) 共 12 参数。前进 6 继续。
- 0xC：找不到报“setpos”/“無效的角色\nGUID[%d]”；原操作数等于事件角色 id 时 lastAction/lastDirection = −1、旗标去 0x80000；MoveRoleTo(角色, 列<<4, 行<<4, 0, −1, −1, −1)；前进 8，角色为控制角色时玩家锁定 |= 0x8000；继续。
- 0xD：找不到报“Talk(Step)”/“角色號碼(GUID:%d)不存在此地圖(%d)”；旗标无 0x2000000 时 ScriptStep；前进 4 结束本帧。0xE：说话者（0xFFFD 为事件角色）对话状态为 0 时前进 4；结束本帧。
- 0x10/0x11：72 条移动记录中角色相同、种类 2，且旗标 0x40000000 为 0（0x10）或非 0（0x11）者存在时 SeekScript 到目标、游标归 0、连续模式清零；否则前进 8。0x12：ResumeMove 为真时前进 4；角色旗标去 0x80000000、延迟 0；继续。0x13：角色 1..roleCount−1 中旗标 0x80000000 者 ResumeMove 并同样清除；前进 2。0x9D：只前进 8（swd3e 不记返回地图）。
- 0x15/0x16：GameFlag（返回 0/1）异或（命令为 0x16）为 1 时跳转。0x17/0x18：0xFF00 结尾的旗标表，逐个把“当前角色号”变量写为 旗标>>3 并计数；全部（0x17，空表也算）或任一（0x18）设置时跳到表尾后的 dword，否则前进 2×个数+8。0x19/0x1A：设置/清除旗标，调试串 "fON [%d]"/"fOFF[%d]"；前进 4。0x1B：ChangeMap(6 个字, 1)；前进 0xE。
- 0x1C：找不到时 UpdateRoleRecord(id, …, talk, 0x1000, …, 0x8080)；找到时释放名字标签（+0x38）并清 +0x34；该角色的移动记录种类 2 时 +8..+0xE 置 0xFFFF；种类 1 时角色不在格点则（非 Solid 时）清格、按当前方向的步长表 0x004AA614/0x004AA634 退回格点、RemoveRole(id, 层, (y>>4)−1, 0)，记录清除；之后旗标 |= 0x1000、路线号 +0x1C = talk、步序 +0x18 = 0；前进 6 结束本帧。
- 0x22：时钟 0x004C655C = 操作数，>1000 时归 0。0x23：操作数低字节 > 时钟低字时前进 8，否则 SeekScript（游标不归零，原有行为）。0x24：时钟 > 标记 0x004D3C78 + 操作数（无符号）时 SeekScript 后仍前进 8，否则前进 8。0x25：标记 = 时钟。

- 0x32/0x46/0x49：已有平移时报“前一個捲動指令還沒有結束”；平移量取操作数（0x32）、目标格减镜头格（0x46）或 CameraAround 角色后的差（0x49），步长取其后两字；平移量为 0 的轴步长清 0；×16 后不能被步长整除时报错并改为 4（除零报错地址改为 swd3e 的 0x0042D482/0x0042D4C0）；负向取反步长；越出地图四边时夹取并报“捲動將超出螢幕範圍…”（参数为四个原操作字与镜头格）；前进 2×步长位置+4（10 或 8）并留在 valueB。宽地图下的轴向归零为已登记增强（第 301 行）。0x33：四个平移量与步长都为 0 时前进 2。

## Talk::RunEvent（0x0042BAF0）指令 0x12 复核（第一遍内修正）

- 发现差异：0x12（恢复移动）在找不到角色时，原程序（0x0042C63B 起）不检查序号即调 RolePath::ResumeMove(−1)（0x0042C64F）；ResumeMove（0x00432630）以 序号 × 0xE4 读移动记录表 0x004D3FD8 之前的 dword（0x0043265A，地址 0x004D3EF4，位于 .data 未初始化部分，属 0x004D3ED8 对象的 +0x1C，无代码按该地址直接写），位 31 为 0 时返回 1；返回非 0 时剧本偏移与指针各 +4（0x0042C65F、0x0042C664）；最后清表外旗标位 31 与 +0x74 字（0x0042C686–0x0042C698），返回 1。源码原写 `run.found < Roles && ResumeMove(...)`，找不到角色时不前进又返回 true，同一帧反复执行 0x12（死循环），第一遍未按 −1 出口核对而误判 exact。
