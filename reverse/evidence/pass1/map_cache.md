## 0x0042A180 MapCache::DecompressMap — exact（越界已登记）

- 大小为 0：错误框“地圖快取製作”/“這地圖是舊格式”（0x004B2278/0x004B2288）后返回。打开 data\<单元>.cm（OPEN_ALWAYS，读写）失败：记“DecompressMap ,%s can't open”，原程序随后 free 了 cFile 内的错误文字缓冲（无效释放，新增偏差行）。定位单元文件 0、HUGE.lmf 到 base+size。
- 旧格式：读 0x1A8 字节头（失败则关闭返回）；总长 +0x10 写出参数、块大小 +0x14；块缓冲 = 块大小 + 块大小>>10；块数 = (块大小 + 总长)/块大小；第 i 块长取 +0x1C+8i，读入（失败记“DecompressMap ,read block fail when ”、关闭、释放后返回）、解压、写出 min(剩余, 块大小) 字节（16 位地图先转换像素）、剩余减块大小；进度 15 + 45i/块数。
- MSF3：读 0x400 字节头；总长 +8 写出参数、块大小 +4；总长为 0 时直接结束；第 i 块在 +0x10+8i：偏移（加 base 定位）与长度；解压后写出解压长度（16 位地图先转换）、累计；进度 15 + 45(i+1)/块数；直到累计恰等于总长。
- 实现 DecompressMap/DecompressMsf3 同此（常量 kProgressStart 15、kProgressSpan 45、TrueColorBits 16）。第 322 行扩充为两种头都不检查块表与块长、块大小为 0 时除以零。

## 0x0042A7D0 Field::LoadMap — exact（越界、平台替换已登记）

- 关闭 HUGE.lmf，释放区块与地块缓冲，MapScale::Clear，释放区域链表并清 0x34 字节；路径按安装类型 0x004E55A4：1 为光盘路径 0x004D1840 的 "swd3e\HUGE.lmf"，2 与 0x34 为安装目录，其余为空（实现一律安装目录，deviations.md 第 100 行已补）。打开失败记“Load(%d)  ,LMF can't open:%s”返回 0。
- 目录：首 dword 为目录位置，项数 = (文件长 − 位置 − 1)>>4，16 字节一项，+8 为地图号、+0 为起点（0x004F01B8）；找不到时系统旗标 |= 4、记“LoadMap3(%d) ,MapCode fail:%d”、返回 0。起点处标记非 'MSF3' 时错误框“LoadMap3”/“地圖[%d]是舊格式”后照读。
- 头 0x400 字节：宽 +0x100、高 +0x102、色深 +0x104、unk0C +0x106、层数 +0x108（各零扩展为 dword）、阴影种类 0x004D183C = +0x10C、unk14 = 0；ResetRows；名称首字节 0；解除快取视图并关闭；视图 = GetCachedMap(地图, 起点, +0x38, 0)。
- 地块：层×宽×高×4+4 字节自 +0x118 读入，原地取每个 dword 的低字。区块：+8/+0xC 读入后解压到 宽×高×4 字节。区域：+0x10/+0x14，首 dword 为数，0x30 字节一项，节点 0x34 字节清零后头插，+4..+0x10 取 id/事件/旗标/阻挡旗标，名称 strcpy。物件：+0x18/+0x1C，首字为数，自 +8 每 0x10 字节：编号 +0xC，偏移/压缩长/解压长/旗标写四张 0x300 项表。
- 角色：+0x20/+0x24，首字为数，自 +8 每 0x10 字节：角色表第 roleCount 项，动作区 0x29 dword 清零后 0x0040DF70；放置字 +0xA：层 (>>8)&3 查 {2, 0, 1}（3 时读到返回地址 0x0040CB13），或上 0x9000，绘制偏移 (低字节>>4)&0xF 与 &0xF；x +2、y +8、id 0xFFFF；x > (宽+0x28)*16 或 y > (高+0x1E)*16（无符号）时不占位；物件旗标 &0x1000100 时自 起点+偏移 读 0x10 字节取动作号与动作，否则动作号 0、图号 = 物件号、动作 y = y − (+4)；InsertRole(层)、roleCount 加 1。
- 叠层：+0x28 非 0 时，首字为数，自 +8 每 0x18 字节：压缩长为 0 跳过；解压出 RLE 图，节点 0x20 字节：宽高取图 +2/+4，左上右下 = 字节 +0xE..+0x11 ×16，种类 = +0xC&7、视差 X = (字节>>3)&0xF、视差 Y = (字>>7)&0xF；图格式 &0x3FFF 为 0x10 时转显示格式（0x00401680 写回宽高）；头插 0x004C4A7C。比例图 +0x40/+0x44：解压长取数据 +4，自 +8 解压后 SetPicture；行比例 +0x48/+0x4C/+0x50：解压后 SetScales。返回 1。实现同此；第 320 行补充引用越界物件号、区域名 strcpy、读入长度不检查。
