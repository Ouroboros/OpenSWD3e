# 第一遍汇编验证：pic 模块

每条：函数、结论（exact／diff）、从汇编独立推导的要点（分支、出口、位宽、副作用）、依赖数据及其核对位置。

## 0x00401000 RleCodec::Encode — exact

- 入口：`*size = 0`、填充标志清零；格式 0x10 走 16 位分支（缓冲 w×h×6，size 以字计，表头 4 字），否则 8 位分支（缓冲 w×h×3，size 以字节计，表头 8 字节，格式字写入参数原值）。
- 每行：行头占位；行旗标初值 0x8000，首像素（8 位分支零扩展后）等于 16 位填充色 `0x004EF588` 或跳过色 `0x004EF530` 时清零（8 位分支也与 16 位颜色比较）。
- 行内循环为 do-while（宽 0 仍处理一次）：像素等于填充色时再判跳过色——两者都等则作跳过段（0x8000|长度），否则填充段（0xC000|长度，置“有填充”）；只等于跳过色作跳过段；其余为字面段，首像素无条件写入，之后遇填充或跳过色即止，长度不含种类位。
- 行长：初值 2，字面段 +2（计数字）+像素字节，段码 +2；行头写 (行长+2)|旗标；行尾写 0；最后整图再写 0。
- 8 位分支段计数循环以 dword 比较零扩展字节与 `0x004EEE90`／`0x004EEEC4`，字面循环以字节比较；两者在颜色值小于 0x100 时等价（颜色由设置函数写入，见其验证）。
- 出口：按计数分配新缓冲复制并释放旧缓冲；有填充段时表头字节 7 |= 0x80（FormatFlag15）。
- 依赖：RLE 颜色 `0x004EF584`（标记）、`0x004EF588`、`0x004EF530`、`0x004EEEC4`、`0x004EEE90` 均在 .bss，运行时设置，于设置函数核对。

## 0x004014B0 RleCodec::Decode — exact

- 标记字零扩展后与 dword `0x004EF584` 比较，不等返回 0；宽、高写出参数，格式字取 &0x7FFF 写出参数（格式无效时这些仍写入，返回 0）；0x10、8 以外返回 0。
- 分配 宽·高·2（16 位）或 宽·高（8 位）；首行头为 0 时直接返回该块。
- 行循环：行头非 0 时逐个读段码直到 0；段码 &0xC000 为 0 是字面段（逐像素复制），0x8000 写跳过色，0xC000 写填充色，0x4000 什么也不做且不前进源指针；计数取 &0x3FFF，以 16 位计数 do-while 比较，计数 0 绕回 65536 次。
- 16 位分支用 `0x004EF530`／`0x004EF588` 的低字，8 位分支用 `0x004EEE90`／`0x004EEEC4` 的低字节。行长字未使用。
- 分配块由 Allocate（0x0043DA70，按 (n+0xF)&~3 分配并清零）提供，编码未覆盖的像素为 0（实现原先按调试堆填 0xCD，已改为 0）。
- 偏差：越界写读见 deviations.md（0x004014B0）。实现以 `std::optional` 表示返回 0；调用者是否读取格式无效时写出的宽高，在调用者处核对。

## 0x00401680 RleCodec::ConvertToDisplay — exact（修正后）

- 标记字不符返回 0；宽、高、格式（&0x7FFF）各在指针非空时写出（实现以引用接收，调用者总传入）；格式非 0x10 返回 0。
- 行循环：行头非 0 时读段码；字面段（&0xC000 为 0）以 &0x3FFF 计数调 0x00427680（经 `0x004B1E84` 转换器：0x0040C560 空、0x004276C0、0x004276F0、0x00427760，皆 do-while：计数 0 时转换一个字），源指针前进 计数·2。返回 1。
- 差异（已修正）：计数 0 的字面段原程序就地转换紧随的段码字（即下一段码），实现原先不转换。修正后单元与黄金测试通过。
- 第 0x004016F5 起的“首段为字面”标志与 0x0040173F 的交替标志只写不读。

## 0x00401780 RleCodec::ConvertTo16 — exact（修正后）

- 结构参数：+0 数据、+8 调色板、+0xC 宽、+0xE 高、+0x10 大小。标记不符直接返回；格式非 8 时调 0x00401680（宽高写入图片，格式写入局部）后返回，不改大小。
- 8 位：分配 4·宽·高（清零）；表头复制标记、宽、高，格式 (原值&0x8010)|0x10。每行：行头槽、首段码照抄；字面段逐字节经调色板取 16 位色，再整段经 0x00427680 转换；其后段码照抄；行长 = 4 + 2·像素 + 2·后续段码（含行尾 0）。
- 末尾：结束槽写 0；计数 ebp 比实际多 2 字节，从工作块复制，工作块由 Allocate 清零，故多出的字为 0；释放旧数据与工作块，写入新数据与大小。
- 差异（已修正）：实现原先在末尾追加 0xCDCD（沿用调试堆假设），改为 0。新增单元测试直接核对输出字节；正传黄金结果中相应 7 个情景改为排除（见 reverse/evidence/tests/legacy-goldens.md）。
- 偏差：无调色板时空指针取色（deviations.md 0x00401780），计数 0 与工作块不足（同表 0x00401680 行）。

## 0x00401950 RleCodec::ConvertTileTo16 — exact（修正后）

- 输入为 0x200 字节调色板加 8 位 RLE；标记或格式（&0x7FFF 不为 8）不符直接返回。分配 2·宽·高+0x1000（清零）；表头同上。
- 行循环与 0x00401780 相同，字面计数以 16 位比较（计数 0 绕回 65536），像素取自块首调色板；行尾写行长后预留下一行头槽。
- 末尾：结束槽写 0，ebp 加 2 后截为 16 位，按此分配并复制，写回数据与大小。多出的字来自清零工作块，为 0。
- 差异（已修正）：同 0x00401780，末尾 0xCDCD 改为 0；单元测试覆盖。

## 依赖数据

- RLE 颜色 `0x004EF584`、`0x004EF588`、`0x004EF530`、`0x004EEEC4`、`0x004EEE90` 位于 .bss，初值由设置函数写入，在其所属函数验证时核对。
- 分配函数 0x0043DA70：(n+0xF)&~3 字节并清零，n≤0 返回空。
