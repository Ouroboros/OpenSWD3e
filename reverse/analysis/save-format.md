# swd3e 存档格式（save\<n>.sav）

依据：swd3e.exe 0x00406EC0（存档帧内联的写入与读取）、0x00409480（存档预览）。数值均为小端；“压缩块”指 `dword 压缩后长度, dword 原长度, 压缩数据`（MapCache::Pack／Unpack 的格式，读取只用压缩后长度）。

| 偏移／顺序 | 长度 | 内容 | 依据 |
| --- | --- | --- | --- |
| 0x0000 | 0xC | 存档时间 `%04d%02d%02d%02d%02d` 的前 12 字节（年月日时分） | 写入 0x00406EC0；预览按 `____/__/__ __:__` 填入 |
| 0x000C | 0x9600 | 160×120 缩图（地图帧缩为四分之一，RGB555） | sub_40E3F0、sub_4276A0 |
| 0x960C | 0x20 | 地图名 | String1 |
| 0x962C | 压缩块 | 游戏旗标 0x400 字节；原长度字段写 0x400 | asm/00406EC0.asm 0x004079A7 `push 400h` 后 `sub_43D080`；游戏目录 Save/0.sav、1.sav、10.sav、14.sav 该处均为 0x400 |
| 其后 | 压缩块 | maps.dat 角色表（表 1，每条 0x18 字节、12 字），原长度为表长 | 读取时每 0x18 字节调用 UpdateRoleRecord（0x0040D7C0），第 12 字为角色变量 |
| 其后 | 7×dword | 队长编号、当前地图、控制角色的格子 x、y、act、动作、方向 | 读取直接写入控制角色的 x、y（格子单位）再交给 LoadCity |
| 其后 | 压缩块 | 队伍数据：时钟 dword、变量 0x100、4 个角色记录 0xF0（每条 +0x26 起 4 字节清零）、装备 0x40 字、4 个法术表（各以 0 结尾）、物品（编号, 数量；待入数量以编号 |0x8000 另记）以 0 结尾、maps.dat 表 2 的场景音乐记录（每条 8 字节）以 0 结尾 | 读取时法术逐个插在表头后（顺序反转）；音乐记录在 cue 0x800 未置时写回 |
| 其后 | 0x80 | 四个角色的三段名（RoleName ×4） | byte_4E4C30 |
| 其后 | dword | 累计游戏秒数 | 0x004C66A8 |
| 其后 | 0x40 | 返回点：+0 列、+2 行、+4 地图、+6 跟随 act、+8 计时帧、+0xC 计时事件 | 地图为 0 时用当前地图与控制角色位置 |
| 其后 | 0x180 | 战斗块 4×0x60 | 0x004C6700 |
| 其后 | dword + n | 名声计数（sub_48AA80 的输出） | |
| 其后 | 0x84 | 震动：+0 保持、+2 帧数、+4 偏移 0x80 字节 | |
| 其后 | 压缩块 | 两段 0x34 字节的地图提示文字（不可传送城镇、不可传送出口），原长度 0x68 | 读入 0xA8 缓冲区，首字节非 0 才保留 |

读取按“已用字节 < 文件长度”逐段进行，缺少的段保持新游戏的值。外传在写入存档前、打开文件成功后，若变量 2（符鬼）为 1～5，先把符鬼记录写入 swdghost.dat 对应槽；读档结束时先 `TalismanGhost::Reset(0)`，再按变量 2 从 swdghost.dat 载入。
