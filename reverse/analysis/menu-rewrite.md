# menu 模块按外传改写计划

依据：swd3e.exe 0x0043E900..0x00457xxx 的菜单函数（函数表 module=menu）。外传菜单是重新设计的，不能沿用正传布局：

- 角色栏改为左侧纵向三栏（0x004BE5D4 起 4×0x1C 的标签表，x=0x0E，y=0x34/0xB6/0x138/0x1BA），只列入队的角色：0x00441910 按旗标 0x1E..0x21 建立可见角色表（0x0050A344，个数 0x0050AB90），0x00441960 把栏位换成角色（栏位 >2 为 -1）。
- 帧绘制：Present 为 0x0043F110（背景在 x=滑动+0xB4，页面绘制，再画标题 0x0043F3B0、标签面板与 0x0043F4A0）。0x0043F4A0 按模式绘制：1 三个角色栏（名、等级与所需经验、三条量与比值、战败灰化）；2 当前角色的详细面板（属性、七项能力、五项抗性、装备比较的增减）；3 符鬼页（种类图 0x2333、符鬼的各项数值 TalismanGhost::Stat、比较增减、0x00449780 的图）。
- 文字以 0x00440570 绘制（右下偏一像素的阴影色，再画两次正文，样式 1）。
- 进入菜单先调用 0x00441910；系统页（3..6）进入时刷新图片缓存（0x004367D0），不关闭档案。

## 阶段

1. 框架：0x00441910、0x00441960、BuildTabs 0x0043EEB0、Open 0x0043EDE0、Run 0x0043EB10、Present 0x0043F110、标题 0x0043F3B0、标签 0x0043F4A0、0x00440570、0x00449780（保留重建的连续动作增强，记入偏差）。
2. 页面表 SetPage 0x00440CF0、InitActs 0x0043E900、滚动条 0x004405E0。
3. 各页：物品（menu_items）、装备（menu_equip）、法术（menu_skills）、状态（menu_status 与外传新增 0x0044DA00..0x0044DF60）、系统页签（menu_options）、祭坛（menu_altar 与 0x00443D40、0x00444630、0x00444950）、图鉴（menu_bestiary）、商店（shop）。
4. 未配对函数逐个归入上述页面。

每完成一个阶段即编译、测试、登记并提交；进度以函数表为准。
