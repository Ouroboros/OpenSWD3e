# 平滑画面改由显卡叠放（smooth-gpu 分支）

## 问题

平滑画面（[display] render_scale，偏差表 render-scale 分支各条）原先在两帧之间按 N 倍在 CPU 上交错重画整张地图（N = 4 时为 3616×1920），每次刷新再上传约 14 MB，CPU 占用高。

## 做法

- 每个游戏帧（约 35 ms）按原版绘制代码（PaintWorld）把地图录制成若干层，交给显卡。
- 两帧之间每次刷新只做叠放：各层按镜头与角色此刻的精确位置（1/N 像素，浮点）以最近邻缩放画到窗口。
- 没有退回 CPU 交错画法的情况。影片帧与位置未定的帧把该游戏帧的画面整张交给显卡缩放。

代码：src/map/field_view_gpu.cpp（录制、叠放），src/platform/display.cpp（Display::Layer 等），偏差表「平滑画面：显卡叠放」。

## 分层

按原版先后叠放，遮挡与原版相同。

- 地面层（第 0 层）：底色、叠图、图块，以及不能单独成层的角色；按 1 倍录制。
- 角色层：每个角色一层（RecordSprite）。
  - 会按深度缩放的角色按 2 倍交错录制（2×2 张取样画面），不缩放的（无编号或 NoDepthScale）按 1 倍。
  - 层跟着角色（ClaimLayer）：角色进出录制范围时，其他角色的层不移位、不重画；离开的角色的层保留一阵。
  - 带气泡、附加动作或名字的静止角色不单独成层（这些画到图片以外）；移动时单独成层，名字的范围计入层的大小。
  - 加法画的角色（Additive、ScaledGlow、ZoomAddTinted）只录黑底一遍，以加法叠放。
- 静止层：两个角色层之间有别的内容时才建（RecordStill）；范围按第一张取样画面实画的像素定（名字、气泡、附加动作都在内）。
- 透明度：静止层与角色层在黑底、白底各录一遍，算出每个像素的不透明度；影子在白底上另录一层，以减法叠放。
- 有视差叠图的地图：所有叠图按镜头此刻的位置由显卡画（RecordOverlays），视差按精确镜头位置连续计算；地面层改为黑白两遍录制，透出叠图。
- 屏幕上固定的内容（聚光灯、剧情动画）：存在时按镜头的整像素位置重新录制。

## 录制

- 何时录制：游戏帧换了、录制画布的格（64 像素网格，四周留 32 像素）换了、移动中角色的起停或动作帧变了。镜头在格内移动不录制。
- 第一张取样画面完整画一遍，与上次比较，找出变了的层；其余取样画面、白底、影子三遍只画变了的层（recordSkip），没变的层不重画、不上传。

## 特效与界面

- 两帧之间移动的特效（精灵、落叶、闪电、萤火虫、天气、聚光灯、第二组剧情动画）每次刷新记成绘制指令（Painter::SetRecorder），由显卡按各自的混合方式画；元素保留亚像素位置。
- 热浪与水波：按原版的移行与折射算出每个像素取自何处（每个游戏帧一次），由显卡从地图的副本复制。
- 界面（画线、对话框、头像、金钱、取名框、系统按钮、指针、最后画的内容）在 640×480 上于黑底、白底各画一次，叠在最上。

## 取位置的时机

录制赶不上下一次刷新时，录制完后把运动时钟推到当前时刻再取镜头与角色的位置；赶得上时不推。按「预计显示的时刻」取位置的做法会在游戏帧前停顿，已试过并撤回。

## 已知限制

- 负向染色的加法角色为近似（原版先加再减，结果在 0 处截断）。
- 没有减法混合的渲染器（SDL 软件渲染器，即 Linux 测试程序）不画影子。
- 菜单画面背后的地图仍是该游戏帧的原分辨率画面（待做：打开菜单时读回显卡画面）。

## 验证

- Linux 测试程序：同一帧显卡叠放与 CPU 交错画法逐像素对比（大雁岭、黑山镇、魔界中原、有视差的 79 号地图、各特效）；差异为影子（软件渲染器）与不到 1 像素的取整差。
- Windows（用户）：与 master 版双盲比较分不出；帧间隔与镜头位移统计不差于 master；魔界中原、黑山镇确认顺滑。
