# OpenSWD3e

《軒轅劍參外傳 天之痕》的重制执行程序。

它取代原版的 `swd3e.exe`，读取你已安装的原版游戏资料，在现在的 Windows 上直接运行。剧情、战斗、数值与各种规则都和原版一样，连原版的小 BUG 也保留；会让游戏崩溃的问题则已修正。

本项目不含任何游戏资料，需要你已有原版游戏。

主页：<https://ouroboros.github.io/OpenSWD3e/>

## 和原版相比

| 方面 | 原版 | 重制版 |
| --- | --- | --- |
| 游戏目录 | 由安装程序写入的目录 | 游戏资料和存档可以放在任意目录，目录名可以有中文 |
| 光盘 | 最小安装时进入地图、播放影片要放入光盘 | 不检查光盘，所有资料从游戏目录读取 |
| 字体 | 需要系统装有細明體 | 自带字体 |
| 窗口 | 640×480 独占全屏 | 窗口运行，任意缩放，`Alt+Enter` 切换全屏，记住窗口大小 |
| 切到其他程序 | 游戏暂停 | 继续运行，只有最小化时暂停 |
| 画面 | 每 35 毫秒画一帧，固定 640×480 | 可按显示器刷新率平滑显示，地图可填满宽屏（见「设置」） |
| 启动画面 | 每次都显示 | 可以跳过，直接进入标题画面（见「设置」） |
| 隐藏道具 | 没有提示 | 看不见的调查点和没打开的宝箱可显示提示箭头（见「设置」，默认关闭） |
| 走路与跑步 | 每次启动都是走路；按 R 切换时整个游戏停顿 0.2 秒 | 按 R 即时切换，下次启动时保持上次的选择 |
| 设定 | 离开设定页才保存 | 改了立即保存 |
| 战斗截图 | 按 P 存到 `C:\snap`，文件夹不存在时不存 | 和地图截图一样存到游戏目录的 `ScrnShot` 文件夹 |
| 商店买卖数量 | 左右键每次加减 1 | 按住 Shift 再按左右键，数量直接减到 0 或加到最多（卖：全部；买：银两够、合计不超过 99） |
| 地图全景 | 没有 | 地图上按 Tab 打开当前地图的全景大地图（游戏暂停），标出主角位置和各出入口通往的地方；滚轮或 `+` `-` 缩放，拖动或方向键移动，Home 回到主角，Tab 或 Esc 关闭；再次打开时保持上次的缩放 |
| 状态页 | 不显示閃躲、異常、默契、反應与学绝技的进度 | 属性区行距压紧：经验合为「當前/下一級」一行，下面「絕技」显示绝技点与学下一个绝技所需的点数，五行抗性右边显示这四项数值 |
| 战斗开场 | 进入战斗时随机一位角色先摆一段开场 POSE，大家等他摆完 | 可以跳过，战斗立刻开始；摆 POSE 的那位角色照旧最先行动（见「设置」） |
| 战斗 | 行动条满了全场暂停，自动弹出指令面板 | 可选「即時行動」：和《雲和山的彼端》一样，行动条满了不停住全场、不自动弹出指令面板，满条的角色排队，按确认键才打开菜单，可以在满条的角色之间切换；只有打开法术、物品等列表或有单位出手时才暂停（见「设置」） |
| 自动战斗 | 只用普通攻击 | 可让戴着「連擊」饰品（武聖手鐲、姜公膽）且体力足够的角色自动使用「連擊」（见「设置」，默认关闭） |

每一处和原版不同的行为都记录在 [deviations.md](reverse/analysis/deviations.md)。

## 安装与运行

1. 准备好原版游戏目录，例如 `E:\Game\swd3e`。
2. 从 [Releases](https://github.com/Ouroboros/OpenSWD3e/releases/latest) 下载最新版的压缩包，解压后得到 `OpenSWD3e` 文件夹，里面有 `swd3er.exe`、`asset` 文件夹和设置文件 `swd3er.toml`。可以整个放在任意位置，也可以把里面的东西放进游戏目录。
3. 如果没有放进游戏目录，用记事本打开 `swd3er.toml`，在 `[paths]` 里写上游戏目录：

   ```toml
   [paths]
   data_dir = 'E:\Game\swd3e'
   ```

4. 运行 `swd3er.exe`。

## 设置

exe 旁边有两个设置文件：

- `swd3er.toml`：你自己的设置。程序只读不改，注释和顺序都保留。
- `swd3er.default.toml`：程序自动保存的设置，包括游戏里改的设置、按键和退出时的窗口大小。

同一项两个文件都写了时，以 `swd3er.toml` 为准，这时在游戏里再改只在当次有效。`swd3er.toml` 里每一项都带着说明，默认被 `#` 注释掉，删掉行首的 `#` 就会生效。值写错或没写时取默认值，写错的会在日志里记一条警告。

下面是 `swd3er.toml` 的例子，除了游戏目录，写的都是默认值：

```toml
[paths]
# 原版游戏目录。不写时用当前目录，所以把 exe 放进游戏目录就不用写。
# 相对路径以 exe 所在的目录为准。路径用单引号时反斜杠照写，用双引号时要写成 \\。
data_dir = 'E:\Game\swd3e'
# 存档目录。不写时和原版一样存在游戏目录的 save 里。
save_dir = 'E:\Game\swd3e\save'

[window]
# 窗口的宽和高，至少 640×480。画面保持原来的比例尽量填满窗口，比例不同时留黑边。
# 这三项不写时，用上次退出时的窗口大小。游戏里按 Alt+Enter 切换全屏。
width = 1280
height = 960
# 启动时是否最大化。
maximized = false

[display]
# 以下五项也能在游戏里改：标题画面的「環境設定」，或游戏中按 Esc →「設定」→「顯示設定」。

# 平滑畫面。游戏逻辑仍和原版一样每 35 毫秒走一步，移动、淡入淡出等动态在两步之间
# 按显示器刷新率连续画出，高刷新率显示器更流畅。false 时和原版一样每 35 毫秒画一次。
smooth_motion = true
# 垂直同步。等显示器刷新再显示，消除画面撕裂。
vsync = true
# 每秒最多画几帧，可写 30～1000；0 表示不限，开着垂直同步时就跟随显示器刷新率。
# 只在平滑畫面开启时有效。
frame_rate = 0
# 平滑畫面按几倍精度绘制，可写 1～8。倍数越高，镜头和人物移动越细，也越耗 CPU
# （2 倍约为 1 倍的 3～4 倍）。"auto" 按窗口大小取能完整显示的最大倍数，最多 4 倍。
# 只在平滑畫面开启时有效。
render_scale = "auto"
# 地图填满宽屏窗口，能看到更大范围，对话框仍在中间。
# 菜单、战斗、存档等画面仍是 640×480，两边留黑边。
wide_map = true
# 地图上看不见、但调查后能拿到道具或银两的地方，以及还没打开的宝箱，头上显示一个跳动的箭头（能调查时才显示，拿走后消失）。
item_hints = false

[game]
# 启动时先显示启动画面；false 时直接进入标题画面。游戏里在「設定」第一行切换。
launcher = true
# 地图上默认跑步，false 是走路。游戏里按 R 切换时会记下来，下次启动照旧。
running = true
# 自动战斗时，戴着「連擊」饰品（武聖手鐲、姜公膽）且体力足够的角色自动使用「連擊」。游戏里在「設定」→「戰鬥設定」切换。
auto_combo = false
# 即時行動：和《雲和山的彼端》一样，行动条满了不停住全场、不自动弹出指令面板，满条的角色排队，按确认键才打开菜单，可以在满条的角色之间切换；只有打开法术、物品等列表或有单位出手时才暂停。游戏里在「設定」→「戰鬥設定」切换。
active_time = false
# 開場動作：进入战斗时随机一位角色先摆开场 POSE；false 时跳过，战斗立刻开始，那位角色照旧最先行动。游戏里在「設定」→「戰鬥設定」切换。
start_pose = true
# 调试模式，见下面的「调试模式」。
debug = false
# [game] 里还有音量、文字速度、战斗速度和按键（[game.keys]），和原版「環境設定」里的一样，
# 在游戏里改就行。第一次启动时，这些设置会从游戏目录的 Env.dat 导入一次。

[logging]
# 日志的位置和文件名。每次启动写一个新文件，文件名后面加上启动时间和进程号，
# 例如 logs/swd3er-2026-10-29_14-32-05-127840.log。相对路径以 exe 所在的目录为准。
path = "logs/swd3er.log"
# 记录多详细，从多到少是 trace、debug、info、warning、error、critical。
level = "debug"
```

## 隐藏秘籍

以下都是原版就有的隐藏功能。

### 随时可用的按键

| 按键 | 作用 |
|---|---|
| F8 | 暂停／继续游戏 |
| P | 截图（地图上或战斗中），存到游戏目录的 `ScrnShot` 文件夹 |
| Esc（播放影片时） | 跳过影片 |

### 调试模式

在 `swd3er.toml` 的 `[game]` 里写上 `debug = true` 打开调试模式。之后：

- 战斗中的调试键直接可用。
- 地图上同时按住 右Ctrl + 右Shift + Home + End，才会开启地图的调试键。开启状态记在剧情旗标里，会随存档保存：之后读这个存档或它后来的存档，不用再按就能用，也没有办法关掉（和原版一样）。

地图上：

| 按键 | 作用 |
|---|---|
| F12 | 打开剧情旗标查看画面（只在没有对话时） |
| Ctrl+S／Ctrl+L | 随时打开存档／读档画面（只在没有对话时） |
| Ctrl+F | 立即进入一场战斗（当前地图会遇敌时） |
| Ctrl+F9 | 快速模式（对话自动跳过），再按一次关闭 |
| Ctrl+F1／Ctrl+F2 | 显示／隐藏调试文字与地图格子标记 |
| Ctrl+F3 | 可以穿过障碍物，再按一次恢复 |
| Ctrl+Tab+小键盘 +／- | 调整地图动画的速度 |
| Ctrl+Q | 立刻退出游戏 |
| F4 | 作弊对话框（只限 Windows） |
| F6 | 大部分物品与装备各增加 10 个 |
| F7 | 进入升天小游戏 |

战斗中（按住 Ctrl）：

| 按键 | 作用 |
|---|---|
| Ctrl+F1 | 显示／隐藏战斗的调试信息 |
| Ctrl+F4 | 调试信息里另显示我方四人的战斗数值 |
| Ctrl+X | 攻击不扣敌人的生命，再按一次恢复 |
| Ctrl+Z | 我方全员生命、灵力、体力补满，怒气补满，攻击 6500、防御 155、敏捷 100 |
| Ctrl+W | 敌人全灭 |
| Ctrl+E | 立即结束战斗 |
| Ctrl+K | 下一击为「強攻擊」 |
| Ctrl+D | 我方全员受到 50 点伤害 |
| Ctrl+R | 我方全员受到 500 点伤害，灵力、体力各减 5 |
| Ctrl+V | 敌人全员受到 10 点伤害 |
| Ctrl+T | 敌人的行动条重新随机 |
| Ctrl+F2 | 切换「絕對靈契」／「正常靈契」 |
| Ctrl+F9 | 快速模式（对话自动跳过） |
| Ctrl+C | 中止正在施放的法术 |
| Ctrl+F3 | 停止战斗音乐 |
| Ctrl+F5 | 战斗放慢（每帧 0.1 秒），再按一次恢复 |
| H／J（不按 Ctrl） | 所有角色和敌人向右／向左移动 10 像素 |

## 网页的生成

- `docs/index.html`：手写的主页。流程攻略、神魔異事錄、物品大全与煉妖大全在主页里打开（地址 `#walkthrough`、`#bestiary`、`#items`、`#altar`，斜线后可接名称，例如 `#items/藥草`），也可以单独打开对应的 HTML 文件。
- `docs/bestiary.html`：由 `scripts/bestiary/` 生成。`dump.cpp` 链接 `swd3e_core`，从游戏目录读出 mon.dat 的怪物资料、图鉴立绘（动作 0x3B 的第一帧）、mon.dat 招式表的各招式脚本和 battle.ffd 各场战斗的敌人阵形；`build.py`（需要 Pillow）再扫描 FIGTALK.dat 的战斗剧本，找出剧情战斗中改写敌人数值的命令（生命、攻防敏、等级、五行抗性、招式、变身；招式没有名字，按游戏的叫法写成特殊 1／特殊 2，并与怪物原有的招式比较威力等差别），把它们一起做成单个 HTML 文件，图片内嵌。用法见两个文件开头的说明。
- `docs/items.html`：由 `scripts/items/` 生成。`dump.cpp` 读出物品资料与图片，`build.py` 按物品菜单的分类生成页面，效果、装备加成、熟练与成长按重建代码的规则换算。
- `docs/altar.html`：由 `scripts/altar/build.py` 生成，读物品与怪物资料和 MAPS.dat 的炼妖矩阵与固定配方，按炼妖祭坛的合成规则列出每个结果的配方。
- `docs/walkthrough.html`：由 `scripts/walkthrough/build.py` 生成，正文是 `scripts/walkthrough/walkthrough.txt`（按青衫的《軒轅劍參外傳 天之痕》攻略整理，标记写法见 `build.py` 开头）。物品和怪物名链接到物品大全、神魔異事錄；生成时核对每个名字、商店价格和可偷物品是否与游戏资料一致，对不上的会列出来。
- 各数据页的光标音效是 all.snd 的 0x2E 号音效，由 `scripts/sound/extract.py` 按游戏载入音效的方式还原成 WAV，作为最后一个参数交给各 `build.py` 内嵌。
